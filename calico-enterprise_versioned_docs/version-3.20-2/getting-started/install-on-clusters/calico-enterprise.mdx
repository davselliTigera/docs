# Get a license

## Get private registry credentials and license key

Go to the Support Portal > Licenses > Latest license and download the private registry credentials (`config.json`) and the license key (`<customer-name>-license.yaml`). If the files are not there or you face issues with the Support Portal, contact your Tigera support representative and get the following files:

**Private registry credentials**

Get the Docker configuration file, (`config.json`) that contains a robot account token to retrieve the $[prodname] images from the private Tigera repository. For example:

```json
{
  "auths": {
    "quay.io": {
      "auth": "<ROBOT-TOKEN-VALUE>",
      "email": ""
    }
  }
}
```

**License key**

Get a license key file, `<customer-name>-license.yaml`. For example:

```yaml
apiVersion: projectcalico.org/v3
kind: LicenseKey
metadata:
  creationTimestamp: null
  name: default
spec:
  certificate: |
    -----BEGIN CERTIFICATE-----
    MII...n5
    -----END CERTIFICATE-----
  token: eyJ...zaQ
```
